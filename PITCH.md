# 2048+ — Первая игра экосистемы Yupland

## О проекте

2048+ — браузерная игра на базе классической 2048, расширенная системой апгрейдов, турниров, реферальной программой и интеграцией с NEAR блокчейном. Полностью разработана и автоматизирована с использованием вайбкодинга — от идеи до рабочего продукта без единой строки написанной вручную.

Это первая игра, созданная в экосистеме Yupland, и демонстрация того, как можно быстро и эффективно производить игровые продукты для Web3.

## Цель

Запустить производство игр в экосистеме Yupland. 2048+ — пример реализации: рабочая экономика, блокчейн-авторизация, внутриигровые покупки за токен DARAI, турнирная система с автоматическим распределением наград.

## Механики

**Игровой процесс:** классическая 2048 с расширениями — поля 4×4, 5×5, 6×6, система апгрейдов (шансы плиток, бонусы к монетам, комбо-множители, авто-удаление), отмена хода, удаление плиток.

**Жизни:** 5 бесплатных в день (сброс в 00:00 по Тбилиси). Дополнительные жизни покупаются за DARAI. Купленные жизни не сгорают при суточном обновлении.

**Внутренняя валюта — Минидары:** зарабатываются за слияния плиток, ежедневные входы (прогрессия 10→100 в день), достижения, турнирные награды, реферальные бонусы. Тратятся на апгрейды и игровые действия.

**Турниры:** два еженедельных турнира — по лучшему счёту и по количеству сыгранных игр. Автоматическое завершение каждое воскресенье, награды начисляются победителям автоматически. Призовые места и размер наград настраиваются администратором из игры.

**Рефералы:** +1 жизнь за каждого приглашённого, +100 минидаров когда реферал достигает 2048, +10 минидаров за каждую покупку реферала.

**NFT интеграция:** владельцы NFT из коллекции darai.mintbase1.near получают ежедневную награду +10 минидаров.

## Экономика

Единственная платная механика — покупка жизней за токен DARAI (darai.tkn.near).

Распределение полученных средств:

| Направление | Доля | Описание |
|-------------|------|----------|
| Пул наград для боксов | 85–90% | Накопление средств для запуска системы боксов на портале Yupland. Боксы можно будет приобрести за минидары. |
| Поддержка проекта | 5–10% | Серверы, домен, обслуживание, развитие. |
| Сжигание (Дупло) | ~5% | Токены DARAI отправляются на сжигание для сокращения предложения и поддержки экосистемы. |

## Боксы (планируется)

После накопления достаточного пула наград на портале Yupland появятся боксы — лутбоксы, которые можно приобрести за минидары (внутреннюю валюту игры). Содержимое боксов формируется из собранных средств DARAI. Это создаёт замкнутый цикл: игроки покупают жизни за DARAI → DARAI идут в пул → пул конвертируется в награды боксов → игроки покупают боксы за минидары.

## Технологии

- Фронтенд: единый HTML файл, без фреймворков, работает в любом браузере
- Авторизация: HOT Connector (@hot-labs/near-connect) — HOT Wallet, Meteor, MyNearWallet, Nightly и другие
- База данных: Supabase (PostgreSQL)
- Деплой: Vercel (автодеплой + Cron для турниров)
- Блокчейн: NEAR Protocol (mainnet)
- Токен: DARAI (darai.tkn.near, 18 decimals)
- NFT: darai.mintbase1.near (Mintbase)

## Почему это важно для Yupland

1. Первый рабочий игровой продукт экосистемы — не концепт, а готовая игра с реальными пользователями
2. Демонстрация скорости разработки через вайбкодинг — от нуля до продакшена за дни
3. Интеграция с токеном DARAI создаёт утилити и спрос
4. Сжигание части средств поддерживает дефляционную модель
5. Реферальная система органически привлекает новых пользователей в экосистему
6. Шаблон для производства следующих игр — архитектура, БД, авторизация, платежи уже отработаны
